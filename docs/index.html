Data credit

Credit. Server counts, player exposure and mod rankings come from the ReforgerMods.net public API (reforgermods.net), an independent, community-run Arma Reforger stats service. Per-mod version and server-list detail for the tracked Project Outbreak add-ons comes from ArmaHQ (armahq.com). ArmaHqStats is not affiliated with ReforgerMods.net, ArmaHQ, or Bohemia Interactive. Visit https://reforgermods.net or armahq.com for the live browsers this page is built on.

Method. Once an hour the collector paginates ReforgerMods.net's public API to get every currently-deployed mod's server count and player exposure, from which it ranks the tracked add-ons, every mod matching the configured keywords, and a global top 50. It then reads ArmaHQ's page for each tracked add-on to get the specific servers, versions and slot capacity behind those numbers. Both stay within each site's published rate limits and page-fetch norms. Player counts are the players on servers running the mod, not subscribers.

Missed hours. GitHub's scheduler does not always start the hourly job on time; for days at a time it has run only every four to eight hours. Each run therefore reads ReforgerMods.net's own hourly series for the tracked add-ons and the most-used zombie mods and fills every hour of the last 30 days that has no snapshot. Filled hours are marked in green under the charts, and each reconstructed day is checked against ReforgerMods.net's own daily table before it is kept. An add-on that joins this page later gets its earlier hours from the same series. Hours that neither source covers are hatched red and drawn as breaks, not as zero.

Downloads. Workshop download totals come from the Arma Reforger Workshop listing, read every hour through ReforgerMods.net since 8 October 2026 for every add-on and every zombie mod on this page. The earlier totals, back to 5 September 2026, come from the listing history of the Project Outbreak site and cover its first six add-ons. The Workshop updates its totals about once a day, so the new-downloads bars show one bar per update. A total that falls (the Workshop can reset it when an item is published again) counts as a reset, not as lost downloads.

Built on Project Outbreak Zombies. This list comes from ArmaHQ's own Workshop dependency index, not a keyword search: every hourly run asks ArmaHQ for every mod it currently sees declaring the flagship as a Workshop dependency, drops the add-ons by Project Outbreak itself (they have their own section above), then re-fetches each remaining mod's own download, server and player numbers from ReforgerMods.net.

How servers get it. ReforgerMods.net traces each server's mod list and tells apart a server that loads an add-on directly from one that gets it because another mod needs it. Player-hours add up the players on every server running the add-on, hour by hour, over the last seven days.
